# Routes

TanStack Start uses file-based routing. In this JavaScript version, every `.jsx`
file inside `src/routes` defines a route.

| File | URL |
| --- | --- |
| `index.jsx` | `/` |
| `dashboard.jsx` | `/dashboard` |
| `challenges.index.jsx` | `/challenges` |
| `challenges.$challengeId.jsx` | `/challenges/:challengeId` |
| `collaborations.index.jsx` | `/collaborations` |
| `__root.jsx` | root shell for all pages |

`routeTree.gen.js` is generated by TanStack Router. It is included so the app can
run immediately after conversion, but it can be regenerated when routes change.
